Instructions
Step 1
<a href="/7S3QCKWK">Mix </a>eggs and milk and set aside. Sift together flour, <a href="/HF7TLMS7">baking powder,</a> and <a href="/DPSVTKVY">salt. </a>Place sifted <a href="/RF7SRX43">dry </a>ingredients in a large wooden bowl. Make a well in <a href="/RF7SRX43">dry </a>ingredients and add milk and egg mixture. <a href="/DRM2WPZ4">Stir. </a>Note: (When <a href="/7S3QCKWK">mixing </a>dough, use wooden <a href="/NX588QBK">spoon,</a> not mixer. Dumplings will flop if you do.) Add <a href="/482ZKJDV">bread </a>cubes. <a href="/DRM2WPZ4">Stir. </a>Dough will be sticky. With floured hands, shape dough into 2 loaves, about 5-1/2 inches long. Cover with a large bowl and let rest for 30 minutes. Option: I add a tsp. of caraway <a href="/FYFCQVPR">seeds </a>to the mixture when <a href="/7S3QCKWK">mixing </a>but it's optional.
Step 2
Meanwhile, fill a large pot half full with water. Bring to a <a href="/W7VKDJHH">boil. </a>Reshape dough with hands and drop into water. <a href="/W7VKDJHH">Boil,</a> covered, for 12 minutes. Carefully <a href="/B52FHCF2">turn </a>dumplings and <a href="/W7VKDJHH">boil </a>12 minutes more. Using a large spatula, lift dumplings to a platter. <a href="/45BJSPGG">Prick </a>a few times to let <a href="/WPFKW7GH">steam </a>escape. <a href="/XZBDDD5G">Cut </a>into <a href="/3JDX2Q84">slices </a>with sewing <a href="/Z27T5R5G">thread.</a>
Step 3
Warning you must let the dumplings <a href="/W7VKDJHH">boil </a>for 12 minutes each side or run the risk of it flopping. And it will flop.
